PiggyBank currently integrates with Plaid Sandbox only for development and testing.

No real bank accounts, real financial transactions, or real-money movement are supported by this application in the current phase.

The Plaid integration is inteded solely for testing account linking and retrieving simulated financial data.

Do not configure this application with Plaid Production credentials or use it to initiate real money movement. Any future production financial functionality would require appropriate security controls, compliance review, licensing/regulatory nalysis, and approval before handling real funds.
